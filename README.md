Hi, I'm Yevhen, a Flutter developer from Ukraine.

I build [Say My Frame](https://github.com/saymyframe/smf_flutter_cli), a free and open-source CLI that generates a Flutter app from modules. You pick what the app needs, such as a router, tabs at the bottom, an onboarding, a settings screen, a theme, languages, sign-in or Firebase, and get a project with all of it wired up. To check that the modules work together, CI generates apps from many combinations of them and runs `flutter analyze` and the tests in each.

I also write [a blog](https://saymyframe.com/blog) about the problems I run into while working on it, like the Crashlytics upload-symbols error in `flutter build ipa` or a shared_preferences crash in Android release builds.
